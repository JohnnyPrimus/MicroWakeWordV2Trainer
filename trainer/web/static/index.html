训练流水线

训练流程

按顺序执行。已完成的步骤可以安全重跑，下载与生成的数据会被复用。

  1. 01

    安装训练环境

    待运行

    克隆 microWakeWord 与 Piper，下载语音模型并安装依赖。首次执行耗时较长。

  2. 02

    检查唤醒词发音

    待运行

    生成一条试听音频，确认 YAML 中的 phonetic 拼写符合预期。

  3. 03

    生成训练样本

    待运行

    使用 Piper 生成完整的多说话人和多语速样本集。

  4. 04

    下载背景与负样本

    待运行

    下载 RIR、Audioset、FMA 和预生成负特征，通常需要数 GB 空间。

  5. 05

    试听增强样本

    可选

    随机混合背景噪声和房间响应，快速检查增强配置是否合理。

  6. 06

    构建频谱特征

    待运行

    增强正样本并生成训练、验证和测试所需的 mmap 特征。

  7. 07

    训练与量化

    待运行

    训练混合网络，选择最佳权重并转换为流式量化 TFLite 模型。

  8. 08

    导出 ESPHome 模型

    待运行

    生成可下载的 TFLite 与 V2 manifest。导出参数在右侧设置。
